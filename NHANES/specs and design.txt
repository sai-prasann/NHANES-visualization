2-Some specs (in progress):

*A standard user should be able to browse the results by selecting components and seeing the distribution of the values.
*Visualisations can initially display one or two components. Visualisation will depend on whether components are discrete or continuous values
*statistics will at some point be added to visualisations
*Visualisations may have some filtering components
*Admin interface will allow users to add new studies, see what is installed, etc... Maybe a table for this will be needed
*A search box could be useful for many cases (finding components, etc..).
*The system should allow making calls to python scripts so that machine learning algorithms can be run. This does not have to be implemented now but we must be aware of this.
*Consider policies and store requests (validation)
